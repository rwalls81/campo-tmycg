# Campo TMyCG

Herramientas de campo para las prácticas de Tendencias del Mercado y Consumidor Global
(LNM 7-1 y 7-2 · Mercadotecnia, UTH). Proyecto "Un producto nuevo para Sonora" ·
Dr. Raúl Guadalupe Paredes Barceló.

**App en línea:** https://rwalls81.github.io/campo-tmycg/

Toda la aplicación vive en `index.html`. Los datos que registra cada alumno se guardan
solo en su teléfono; la app no envía nada a ningún servidor. Para cambiar las claves o
activar herramientas por sesión, editar la línea que empieza con `window.TC_CONFIG`
(la zona docente de la app prepara la línea exacta a pegar).
